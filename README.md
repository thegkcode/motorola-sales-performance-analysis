# 📱 Motorola Sales Performance & Customer Insights Dashboard

**An Interactive Power BI Dashboard for Sales Analysis and Customer Insights**

---

## 📌 Project Overview

This project focuses on analyzing Motorola sales performance and customer-related insights through an interactive Power BI dashboard.

The dashboard provides a consolidated view of sales, transactions, product performance, customer ratings, payment preferences, and monthly sales trends. It also allows users to explore the data through interactive filters and visualizations.

## 🎯 Project Objectives

- Analyze overall sales and quantity performance.
- Explore monthly and day-wise sales trends.
- Compare sales performance across mobile brands and models.
- Understand customer ratings and payment preferences.
- Examine city-wise sales distribution.
- Enable interactive analysis using dashboard filters.

## 🎛️ Interactive Features

Users can explore dashboard data using:

- Month-wise selection buttons
- Mobile Model filter
- Payment Method filter
- Brand filter
- Day Name filter

The dashboard visuals and KPI values respond to the selected filters, allowing users to explore different sales scenarios.

## 🔄 Data Preparation & Transformation

Power Query was used to prepare the dataset before dashboard development.

Key transformation steps included:

- Importing the sales dataset.
- Promoting the first row to column headers.
- Assigning appropriate data types.
- Creating a custom column.
- Renaming and reordering columns.
- Removing unnecessary columns.
- Replacing selected values.
- Extracting day names from the date column.

The transformation steps are documented in the `power-query/` folder.
